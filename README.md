# MyHealth

Локальное веб-приложение для просмотра тренировок с Polar H9 (через Polar Flow) и вопросов к AI по своим данным.

- **Обзор** — объём по неделям, время в пульсовых зонах, тренд среднего пульса.
- **Тренировки** — список, график пульса, зоны.
- **Спросить AI** — чат с Gemini (бесплатный тариф Google AI Studio). Над чатом выбирается выборка (вид спорта и период, например «Бег · 3 мес») — в контекст уходят сводка этих тренировок и недельные агрегаты; посекундный пульс конкретной тренировки модель подгружает сама. Готовый контекст кэшируется по выборке и пересобирается только после синхронизации, импорта, демо или смены HRmax, а неизменный текст позволяет Gemini брать его из своего неявного кэша (`AI_CONTEXT_CACHE=explicit` включает явный кэш Gemini, нужен платный тариф).
- **Сон** — заготовка на будущее.

Всё хранится локально в `data/polar.db` (SQLite). В Gemini API уходят только сводки тренировок и, по запросу модели, пульс конкретной тренировки.

## Запуск

Одной командой (Windows): двойной клик по `start.bat` или в терминале

```bat
start.bat
```

Скрипт сам:

1. создаёт `.venv`, если его нет (нужен Python 3 в PATH или лаунчер `py`);
2. ставит зависимости из `requirements.txt`, но только когда файл изменился;
3. проверяет `.env`: если его нет, копирует `.env.example` и открывает в Блокноте; предупреждает, если не заданы `GEMINI_API_KEY` или ключи Polar;
4. запускает сервер и открывает браузер на http://localhost:5000 (порт берётся из `PORT` в `.env`). Если приложение уже запущено, просто открывает браузер.

Остановить сервер: `Ctrl+C`. Без открытия браузера: `start.bat -NoBrowser`. Из PowerShell можно запускать и `.\start.ps1`.

Вручную (или на macOS/Linux):

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; на macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # затем заполните .env
python run.py
```

Откройте http://localhost:5000. Чтобы попробовать без Polar, добавьте демо-данные в разделе «Данные и настройки».

## Подключение Polar AccessLink

1. Войдите на https://admin.polaraccesslink.com своим аккаунтом Polar Flow.
2. Создайте клиента (*Create client*), в поле Redirect URL укажите `http://localhost:5000/oauth2_callback`.
3. Скопируйте `client_id` и `client_secret` в `.env` (`POLAR_CLIENT_ID`, `POLAR_CLIENT_SECRET`).
4. Перезапустите приложение → «Данные и настройки» → «Подключить Polar» → разрешите доступ.
5. Нажимайте «Синхронизировать» после тренировок (Polar Beat должен успеть отправить тренировку в Polar Flow).

Ограничение API: отдаются только тренировки, загруженные в Polar Flow **за последние 30 дней и после подключения**. Более старую историю импортируйте файлами: Polar Flow → тренировка → «Экспорт сессии» → TCX или CSV → «Импорт файлов».

## Ключ Gemini API (бесплатно)

1. Откройте https://aistudio.google.com/apikey и войдите аккаунтом Google.
2. Нажмите *Create API key* и впишите ключ в `.env` как `GEMINI_API_KEY`.

По умолчанию используется `gemini-3.8-flash` — на бесплатном тарифе за неё не платят, но есть лимиты запросов в минуту и в день. Модель и глубину рассуждений можно поменять через `AI_MODEL` (например, `gemini-3.5-flash-lite` для более щедрых лимитов) и `AI_THINKING`.

Учтите: на бесплатном тарифе Google может использовать запросы для улучшения своих моделей, то есть сводки тренировок попадут к Google.

## Структура

```
app/
  main.py      веб-сервер и API
  db.py        SQLite: тренировки, пульс, настройки
  polar.py     Polar AccessLink: OAuth и синхронизация
  importer.py  импорт TCX/CSV из Polar Flow
  metrics.py   зоны, агрегаты по неделям
  ai.py        чат с Gemini, контекст и инструмент get_workout_hr
  demo.py      генератор демо-данных
static/        интерфейс (HTML/CSS/JS без сборки)
data/          база данных (не коммитить)
```
